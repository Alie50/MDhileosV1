# MDhileosV1 — مدحليوس

موقع منشورات من ثلاث صفحات مستقلة، كل صفحة بملف ورابط خاص بها. التصميم عربي RTL بهوية تحريرية (ورق، كوبالت، خط Alexandria).

## الصفحات

| الملف | الوظيفة | الرابط بعد النشر |
|---|---|---|
| `index.html` | تسجيل الدخول | `https://alie50.github.io/MDhileosV1/` |
| `admin.html` | لوحة التحكم وإدارة المنشورات | `https://alie50.github.io/MDhileosV1/admin.html` |
| `posts.html` | عرض المنشورات للزوار | `https://alie50.github.io/MDhileosV1/posts.html` |

يمكن الانتقال بين الصفحات بتغيير اسم الملف في آخر الرابط فقط.

## التشغيل محلياً

من داخل مجلد المشروع:

```bash
python3 -m http.server 8080
```

ثم افتح:

- `http://localhost:8080/`
- `http://localhost:8080/admin.html`
- `http://localhost:8080/posts.html`

## كيف تعمل البيانات

- المنشورات تُحفظ في `localStorage` تحت المفتاح `mdh_posts_v1`.
- جلسة الدخول تُحفظ في `sessionStorage` أو `localStorage` تحت المفتاح `mdh_session_v1`.
- تظهر المنشورات الجديدة مباشرة في صفحة `posts.html` عند فتحها في نفس المتصفح.
- يمكن فتح `posts.html` مباشرة بدون تسجيل دخول.

## ملاحظة أمنية مهمة

هذه نسخة عرض أمامية (Front-end Demo) وليست نظام مصادقة حقيقياً:

- بيانات الدخول مكتوبة داخل `index.html` ويمكن لأي شخص قراءتها.
- المنشورات محلية في المتصفح، ولا تظهر للزوار على أجهزة أخرى.
- للحصول على تسجيل دخول حقيقي ومنشورات مشتركة بين الجميع، يجب إضافة خادم/قاعدة بيانات (مثل Supabase أو Firebase أو API خاص) ونقل التحقق إلى الخادم.

## النشر على GitHub Pages

الموقع منشور من الفرع `main` في جذر المستودع. أي تعديل يُدفع إلى `main` يُحدّث الصفحات تلقائياً بعد دقائق.

## التخصيص السريع

- **الهوية والألوان:** متغيرات `:root` في أعلى CSS في كل ملف.
- **الخطوط:** روابط Google Fonts في `<head>`.
- **بيانات الدخول:** كائن `DEMO` في سكربت `index.html`.
- **المنشورات الافتراضية:** مصفوفة `SEED` في `admin.html` و`posts.html` (يجب تحديثها في الملفين معاً عند تغييرها).
- **الصور:** حقل «رابط صورة الغلاف» في لوحة التحكم، أو اتركه فارغاً لاستخدام الغلاف المرسوم تلقائياً.
